## 二、顾客端操作指南

### 2.1 注册与登录

1. 点击右上角「登录」，或直接访问 `/login`
2. 首次使用点「注册」，填写手机号、密码、昵称
3. 登录后右上角显示昵称，未登录时访问受保护页面会自动跳转登录页，登录后回到原页面

### 2.2 浏览款式灵感库

1. 首页「精选款式」或导航「款式灵感库」
2. 按风格标签筛选（可爱 / 轻奢 / 法式等）
3. 点卡片上的红心可收藏，收藏的款式在「我的收藏」里查看
4. 点「一键套用」可直接把模板作为设计草稿打开在设计台

### 2.3 使用可视化设计台（核心功能）

进入路径：导航「开始设计」或首页「设计你的专属美甲」

**界面结构**

```
┌─────────────────────────────────────┬──────────────────┐
│  左侧：预览区                        │  右侧：素材面板   │
│   ├─ 手模视图（五指可点选）           │   ├─ 甲型        │
│   ├─ 平铺视图（五片平铺对比）         │   ├─ 长度        │
│   └─ 单甲精细编辑（就地放大）         │   ├─ 底胶        │
│                                     │   ├─ 效果层      │
│  工具条：撤销 / 重做 / 同步全指 / 缩放 │   └─ 图案        │
└─────────────────────────────────────┴──────────────────┘
```

**操作步骤**

1. **选择手指**：点手模上任意一根手指，右侧面板的改动只作用于**当前选中的手指**
2. **选甲型**：8 种甲型（圆形 / 方圆形 / 方形 / 椭圆形 / 杏仁形 / 芭蕾形 / 尖形 / 俄罗斯方），点击即切换
3. **调长度**：拖动「长度」滑条，甲片**只向指尖方向延伸**，根部位置不变
4. **选底胶**：从色卡选色，或用色相 / 明度滑条、HEX 输入框自定义颜色
5. **加效果**：在「效果层」里可以**多选叠加** —— 珠光、细闪、极光、猫眼等可以同时存在，每层还能单独调透明度
6. **加图案**：贴花（可从素材库选，也可上传自己的透明底 PNG）、法式、波点 / 豹纹、参数化款式
7. **微调**：拖拽素材可改变落点；用「单甲精细编辑」放大当前手指精修
8. **批量应用**：点「同步到全部手指」把当前手指的配置复制到五指
9. **撤销 / 重做**：工具条上的箭头按钮，支持多步回退

**保存与下单**

点「保存设计」后弹出三选一浮层：

| 选项 | 结果 |
| --- | --- |
| 继续编辑 | 留在设计台，浮层关闭 |
| 保存并加入购物车 | 设计入库并加购，可继续设计 |
| 保存并立即结算 | 设计入库、加购并跳转结算页 |

> 未登录时点保存会先跳登录，登录后自动回到设计台继续。

### 2.4 我的设计

- 查看所有已保存的设计（含预览图、名称、单价）
- 支持「再次编辑」（回到设计台继续改）、「加入购物车」、「删除」

### 2.5 购物车与结算

1. **购物车**：可修改数量、删除条目；空态时有「去设计一副」入口
2. **结算页**：
   - 选择**到店自提**（选门店，免运费）
   - 或选择**商家邮寄**（选收货地址，商品满 ￥99 包邮，否则运费 ￥8）
   - 邮寄模式下可直接在弹窗里新增收货地址
3. 点「提交订单」生成订单，跳转订单列表

### 2.6 订单管理

- **订单列表**：按状态筛选（全部 / 待付款 / 待接单 / 制作中 / 待自提 / 待发货 / 已发货 / 已完成）
- **订单详情**：商品明细（含设计预览图与参数清单）、状态时间线、履约信息
- **待付款**：可「去支付」（模拟支付）或「取消订单」
- **待自提**：显示 6 位自提码，凭码到店核销
- **已发货**：可「确认收货」
- **已完成**：可「评价」或「一键复购」

### 2.7 评价

- 对已签收 / 已核销的订单评价：评分（1–5 星）+ 文字 + 晒图（最多 3 张）
- 每单限评价一次
- 商家回复后可在订单详情看到回复内容

### 2.8 申请售后

**入口**：订单列表里，已完成的订单（已签收 / 已核销）会显示「申请售后」按钮。

**操作步骤**

1. 点「申请售后」打开弹窗
2. 选择**售后类型**：仅退款 / 退货退款
3. 选择**申请原因**（尺寸不合适 / 色差明显 / 做工瑕疵 / 运输破损 / 与设计不符 / 不想要了 / 其他原因）
4. 填写**补充说明**（选填）
5. 上传**凭证图**（选填，最多 3 张）
6. 点「提交申请」

**注意事项**

- 退款金额由系统按**订单实付金额**自动计算，无需填写、也不可修改
- **一个订单只能申请一次售后**，被拒绝后也不能再次提交
- 提交后订单卡片上会显示「售后 · 待商家处理」标签
- 商家处理后你会收到消息通知，订单上的标签同步更新为「已退款」或「已拒绝」

### 2.9 消息通知

**入口**：顶栏的铃铛图标（登录后可见），有未读消息时显示红点数字。

**使用方式**

1. 点铃铛打开通知面板，显示最新 8 条消息
2. 打开面板即自动标记全部已读，红点消失
3. 点某条消息可跳转到订单页查看详情

**会收到哪些通知**

| 场景 | 内容 |
| --- | --- |
| 商家接单 | 订单已接单，正在制作中 |
| 制作完成 | 自提：附自提码；邮寄：待发货 |
| 商家发货 | 快递公司 + 物流单号 |
| 订单核销 | 订单已完成 |
| 订单被取消 | 订单已被商家取消 |
| 售后审核结果 | 申请已通过（含退款金额）/ 被拒绝（含原因） |

### 2.10 个人中心

- 修改昵称、头像、手机号
- 管理「我的设计」「收货地址」（最多 10 条）

## 三、商家端操作指南

入口：`/merchant`（需 MERCHANT 或 ADMIN 角色）

### 3.1 数据看板

首页展示：今日与累计订单数、营业额、待履约订单数、平均评分，以及各模块快捷入口。

### 3.2 素材管理

按类型分标签页管理设计素材：

| 类型 | 说明 | 操作要点 |
| --- | --- | --- |
| 甲型 | 8 种基础甲型 | 代码注册素材，无需上传图片，下拉选择甲型代码 |
| 色卡 | 颜色素材 | 填颜色代码（`#RRGGBB` 格式），列表显示色块 |
| 图案 | 贴图素材 | 需上传图片 |
| 参数化款式 | 代码渲染款式 | 需填代码标识 |
| 装饰件 | 矢量 / 立体装饰 | 矢量填代码，立体传图，二者至少其一 |
| 贴纸 | 含 UGC 用户上传 | 见下方审核流程 |

**通用操作**：新增 / 编辑 / 删除 / 上下架（可批量）。被设计引用的素材**禁止删除**，只能下架。

**UGC 贴纸审核**

1. 顾客上传的贴纸会进入「贴纸」标签页，状态为**待审核**
2. 点「通过」→ 上架，全员可见
3. 点「驳回」→ 对上传者隐藏
4. 待审核的贴纸只有上传者本人和运营角色能看到预览图

### 3.3 模板管理

- 把成品设计保存为款式模板，供顾客在灵感库浏览和一键套用
- **必须上传封面图**（否则后端会拒绝）
- 可设置风格标签、参考价格、排序、上下架

### 3.4 订单中心

按状态分标签页（待接单 / 制作中 / 待自提 / 待发货 / 已发货 / 已完成 / 已核销 / 待支付 / 已取消 / 全部）。

**履约操作流程**

```
待接单 ──[接单]──> 制作中 ──[制作完成]──┬── 自提单 → 待自提（生成 6 位自提码）
                                        └── 邮寄单 → 待发货
待自提 ──[核销自提]──> 已核销（终态）
待发货 ──[发货]──> 已发货（填快递公司 + 单号）
```

**每个订单卡片显示**：订单号、状态、商品明细（含设计预览图）、**设计参数（制作依据，可展开查看）**、履约信息、状态记录时间线、可用操作按钮。

> 「设计参数」是下单时的快照，**不受素材库后续变更影响**，按它制作即可。

### 3.5 售后管理

**入口**：`/merchant/after-sales`（侧边栏「售后管理」）

按状态分标签页（待处理 / 已退款 / 已拒绝 / 全部）。

**每个售后单显示**：订单号、申请时间、顾客（昵称 + 手机号）、售后类型、申请原因、补充说明、凭证图、退款金额，以及拒绝原因与处理时间（如已处理）。

**处理操作**

| 操作 | 说明 |
| --- | --- |
| **同意退款** | 二次确认后置为「已退款」（终态），并自动通知顾客 |
| **拒绝** | 需填写拒绝原因（≤200 字，顾客可见），置为「已拒绝」（终态） |

> 已处理的售后单不再显示操作按钮，不可重复处理（后端有条件更新防护）。

### 3.6 评价管理

- 查看全部顾客评价（评分、内容、晒图）
- 可「回复」评价（顾客在订单详情能看到回复）
- 可「删除」违规评价

### 3.7 公告管理

- 发布平台公告（标题 + 内容）
- 支持置顶、上下线
- 公告在顾客端首页展示，**游客也可见**

### 3.8 门店管理

- 维护自提门店：名称、地址、联系电话、营业时间、排序
- 切换营业状态：**停用后即时对顾客端隐藏**（顾客结算时选不到）

### 3.9 销售统计

图表化展示：销售趋势、履约方式占比、评价分布、设计偏好 TOP5。

## 四、管理端操作指南

入口：`/admin/dashboard`（需 ADMIN 角色）

### 4.1 平台看板

- 平台用户数（顾客 / 商家分别统计）
- 累计订单与销售额
- 销售趋势
- 用户角色分布
- 热门款式 TOP5（按收藏数）
- 待审核贴纸数

### 4.2 用户管理

- **筛选**：按手机号、昵称、状态、角色
- **禁用**：禁用后该账号无法登录，**即使持有有效令牌也无法访问接口**
- **恢复**：恢复后即可正常使用
- **防自锁**：系统**禁止管理员操作自己的账号**，避免误操作导致无人可管理平台

## 五、常见问题

**Q：设计台上改了颜色，为什么别的指头也跟着变了？**
不会。设计台是**逐指独立**的 —— 右侧面板的改动只作用于当前选中的手指。如果想让所有手指一致，用「同步到全部手指」。

**Q：为什么改了甲型，甲片看起来位置没变？**
这是**预期行为**。甲型只改变甲片的前端轮廓（自由缘），**根部位置固定在天然甲缘线上**，不会"跳走"。长度调节同理，只向指尖延伸。

**Q：效果层能同时选几个？**
不限个数，且可以逐层调整透明度。珠光 + 细闪 + 极光 + 猫眼可以同时存在。

**Q：上传贴纸为什么被拒绝？**
贴纸必须是**含透明背景的 PNG**。系统会逐像素校验透明通道，不透明的 PNG 或 JPG 会被拒绝。

**Q：上传的贴纸为什么别人看不到？**
UGC 贴纸需要**商家审核通过**后才对全员可见。审核通过前，只有你自己和商家能看到。

**Q：为什么订单里的设计和我在设计台看到的有一点点不一样？**
如果商家在您下单后修改了素材库，重新渲染可能有细微差异。但**订单里的设计参数和预览图是下单时的快照**，商家会严格按快照制作。

**Q：门店列表里为什么少了一家店？**
该门店已被商家停用。停用后即时对顾客端隐藏。

**Q：为什么支付后订单还是"待接单"？**
支付成功后需要商家接单才会进入"制作中"。商家接单前，您可以取消订单。
